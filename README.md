# G-Operations website — homepage starter

A responsive, static homepage for G-Operations. It uses HTML, CSS and vanilla JavaScript and can be hosted free on GitHub Pages.

## Files
- `index.html` — homepage content and sections
- `styles.css` — responsive modern startup styling
- `script.js` — mobile menu, current year and enquiry email handoff
- `favicon.svg` — browser tab icon

## Before publishing
1. Open `script.js`.
2. Replace `hello@g-operations.example` with an email address you control.
3. Review the service descriptions and ensure you only advertise services you can currently deliver.
4. The enquiry form opens the visitor's email app; it does not store or transmit form submissions to a server. A backend form service can be added later with privacy and spam protections.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `g-operations-website`.
2. Upload all four website files (`index.html`, `styles.css`, `script.js`, `favicon.svg`) to the repository root. You can also upload this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish deploying. Your public address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/g-operations-website/`
   Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.
7. Open the address on your phone and computer to test it.

## Important
- GitHub Pages hosting is free for public repositories, subject to GitHub's current plan and usage terms.
- A custom domain is optional and costs extra; do not buy one until you are ready.
- This is the public marketing homepage only. Customer login, file uploads, admin tools, payments and order tracking are not included yet.
- Do not collect confidential customer documents through this static site. Add secure storage, access controls, consent and a retention policy before enabling uploads.
- The G-Operations name and domain availability have not been checked. Confirm business-name, trademark and domain availability before investing in branding.
